# Збір результатів: Google Таблиця + лист учителю

## Перше встановлення (≈5 хвилин)
1. Створіть Google Таблицю (наприклад, «Результати — Поле дії»).
2. У Таблиці: **Розширення → Apps Script**. Замініть увесь вміст `Code.gs` вмістом файлу `Code.gs` з цієї папки → **Зберегти**.
3. Виберіть функцію `setup` → **Виконати** → надайте дозволи (Таблиця і пошта). З'явиться аркуш «Результати» із заголовками.
4. **Розгорнути → Нове розгортання → Тип: Веб-застосунок**: «Виконувати від імені: **Я**», «Хто має доступ: **Усі**» → **Розгорнути**, скопіюйте URL, що закінчується на `/exec`.
5. Передайте URL розробнику (або впишіть у `GAME_CONFIG.resultsEndpoint` у `games/.../index.html` і опублікуйте).
6. Перевірка: відкрийте URL `/exec` у браузері — має бути `{"ok":true,"service":"nush-quiz-game results"}`.

## Оновлення скрипта БЕЗ зміни URL
1. Apps Script → замініть увесь вміст `Code.gs` новою версією → **Зберегти**.
2. **Розгорнути → Керування розгортаннями** → олівець (Редагувати) біля наявного розгортання → **Версія: «Нова версія»** → **Розгорнути**.
URL `/exec` залишається тим самим, у грі нічого міняти не треба. (Якщо аркуш «Результати» створено старою версією з іншими стовпцями, нові рядки підуть в аркуш «Результати v2».)

## Що записується
Рядок на кожну спробу: дата/час, ПІБ, email, клас, предмет, тема, правильні, всього, %, оцінка, maxScore, тривалість, номер спроби, результати 4 розділів, слабкі теми, стислий рядок відповідей (`id: відповідь: ✓/✗`), ID спроби. Лист власнику скрипта з темою «[Гра] ПІБ — оцінка X/12» і посиланням на таблицю.

- Значення, що починаються з `= + - @`, записуються як текст (захист від формул).
- Повторне надсилання тієї самої спроби (той самий ID) протягом 6 годин не дублюється.
- Ліміт пошти Apps Script для звичайного Gmail — ~100 листів на добу; рядки в Таблицю пишуться й після вичерпання ліміту.
